## NoteX Web Application

This is the note taking application develop using MERN stack, User can login or register using emial and password and create note, update note, delete note, All CRUD operation are performing.

## Tech stack

React.js<br>
Node.js<br>
Express.js<br>
MongoDB<br>

Using MERN tech stack build this web application

## Setup

```npm
git clone "https://github.com/TejasGtech/Note-Frontend-Code.git"
cd Notes
```
## install
```bash
npm install
npm run dev
```

open web app in localhost `https://localhost:3000` or other ports
